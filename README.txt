Boleler.io жаңартуы

GitHub-та index.html, script.js, server.js және style.css файлдарын бірге ауыстырып, commit жасаңыз.
package.json, package-lock.json және boleler-bg.png өзгерген жоқ.
Жаңарту серверге шыққан соң барлық ойыншы бетті қайта ашсын.

Жергілікті іске қосу: npm ci, содан кейін npm start.

Сурет салу: PNG орнына шағын координат топтары, сенсорлық басқару, қалам қалыңдығы.
Сөздер: 178 бірегей сөз/тіркес.
Телефон: тақта мен чат жоғарыда, ұпайлар төменде.

Тексерілді: екі Socket.IO клиенті, сызықтар, тазалау/бояу, жауап табу, қате кезек пен рұқсатсыз сурет салу; клиенттің pointer оқиғалары.
Нақты телефондағы көрініс пен жылдамдықты бірге ойнап тексеру қажет.
